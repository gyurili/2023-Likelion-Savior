# 🌍 Savior - 해외 여행 물가 정보 서비스  

![화면 캡처 2023-08-19 024254](https://github.com/user-attachments/assets/dbdfc8d4-362d-4692-9eed-5f20a95e0fc1)
> 디지털 정보 격차를 줄이기 위한 여행 정보 공유 서비스  
> **주제: 디지털 격차 → 정보 격차 → 해외 여행 시 물가 정보 부족**


<br>


## 📅 프로젝트 개요

- **진행 기간**: 2023년 7월 18일 ~ 2023년 8월 18일
- **참여 인원**: 총 6명 (프론트 4명, 백 2명)

<br>

## 🔎 소개

Savior는 해외여행 시 자주 겪는 **현지 물가 정보의 부족과 바가지 문제**를 해결하기 위한 서비스입니다.  환율, 평균 시세, 사용자 후기 등 다양한 정보를 제공함으로써 여행자 간 정보 격차를 줄이고,  **더 똑똑하고 경제적인 여행**을 도와줍니다.

### 🧩 기획 배경

- 여행지에서 바가지나 불필요한 지출을 막기 위해 필요한 **시세 정보**는 대부분  
  블로그, 카페, 트위터 등 **산발적으로 흩어져 있습니다.**
- Savior는 이러한 정보를 모아서 **한눈에 보여주는 허브 역할**을 합니다.

<br>

## 🧭 주요 기능

- 💱 **환율 계산**: 실시간 환율 정보로 계산해드립니다. (현지 통화 ↔ 원화 동시 표시)
- 🛍 **평균 시세 조회**: 사용자들이 등록한 국가별 여러 상품의 평균 가격을 제공합니다.
- ✍ **여행자 커뮤니티**: 국가별 사용자 여행 후기를 공유할 수 있습니다.
- 🔎 **식당 추천**: 크롤링을 통해 국가별 식당의 리뷰를 공유하고 추천해드립니다.

## 🗂 프로젝트 구조

```
📁 backend/
```
